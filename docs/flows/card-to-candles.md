# Как карта становится свечами

> актуально · 2026-09-10 · три карты шага правят по восемь часов каждая, амплитуда и волатильность считаются в ATR снапшота, сид — инструмент, якорь, шаг и версия движка; формулы из `tarot-alpha.html`, шкала откалибрована под реальные часовые свечи

Код движка — `engine/v1/`. Движок чистый: ни I/O, ни времени, ни `Math.random`. Всё, что попадает в расклад, воспроизводится из снапшота и выпавших карт, и порядок вызовов генератора — часть формулы: поменяешь порядок — старые ссылки перестанут воспроизводиться.

## Сид и окно фиксации

| `SEED_ENTROPY` | Строка сида | Следствие |
| --- | --- | --- |
| `off` (прототип) | `${asset}\|${anchor_ts}\|${step}\|${engine_version}` | один расклад на инструмент в окне таймфрейма; расклад можно записать после того, как пользователь открыл шаги — сервер пересчитает ровно то же |
| `on` | то же плюс `\|${nonce}` | нонс выдаёт сервер при создании расклада, поэтому расклад создаётся до первого шага; в прототипе не реализовано, только поле `seed_nonce` в строке |

- Якорь — время открытия последней закрытой часовой свечи, граница окна — начало часа UTC. Почему закрытой — `candles-from-exchange.md`.
- Хэш строки — xmur3, генератор — mulberry32, оба как в `tarot-alpha.html`. Шум прогноза берёт отдельный генератор от строки `noise|` плюс та же строка сида.
- `engine_version` входит в сид: смена версии меняет и карты, и свечи, старые расклады считаются старым движком.

## Тасовка

- Колода 78 карт. Старшие — id 0–21 в порядке Райдера–Уэйта: 0 Шут … 16 Башня … 21 Мир. Младшие — `id = 22 + масть·14 + (ранг − 1)`: масти жезлы 0, кубки 1, мечи 2, пентакли 3; ранги 1 (туз) … 10, 11 паж, 12 рыцарь, 13 королева, 14 король.
- Три карты без повторов: `i = floor(r()·78)`; повтор пропускается, второе число на него не тратится. Принятая карта перевёрнута при `r() < 0.28`.

## Карта → восемь свечей

Шаг — 24 свечи, карта с номером `k` правит свечами `8k … 8k+7`. Вход: снапшот (168 свечей), свечи прогноза предыдущих шагов, три карты шага.

- `A` — ATR(14) по снапшоту: среднее арифметическое истинного диапазона последних 14 свечей, без сглаживания Уайлдера. Считается один раз от снапшота; прогноз масштаб не меняет.
- `all` — снапшот плюс прогноз предыдущих шагов; `last` — последняя свеча `all`; `ma` — среднее close последних 24 свечей `all`, считается один раз на шаг; `trend` — знак `last.c − all[−24].c`, ноль читается как +1; `dir` в начале шага равен `trend`.
- `m` — вес карты: 1 для старшего аркана, `ранг / 14` для младшего.

Параметры свечи по карте — `drift`, `v` (волатильность), `gap`, `pull`; по умолчанию `drift = 0`, `v = 1.0`, `gap = 0`, `pull = 0`; после правил карты `v = max(v, 0.6)`.

| Старший аркан | `gap`, первая свеча блока | `drift` | `v` | Особое |
| --- | --- | --- | --- | --- |
| 16 Башня | −3 | −0.3 | 1.0 |  |
| 19 Солнце | +2 | +0.2 | 1.0 |  |
| 10 Колесо Фортуны | 0 | 0.3·`dir` | 1.0 | на первой свече блока `dir` меняет знак, `drift` считается уже после |
| 12 Повешенный | 0 | 0 | 0.7 | `pull` = 0.35: болтанка вокруг `ma`, а не нулевая волатильность |
| 18 Луна | 0 | 0.1·`dir` | 2.0 |  |
| 13 Смерть | 0 | 0.4·`dir` | 1.0 | как Колесо: `dir` меняет знак на первой свече блока |
| остальные, номер `i` | 0 | (`i` − 10.5) / 10.5 · 0.4 | 1.0 |  |

Перевёрнутый старший аркан меняет знак у `drift` и `gap`. Режим — это `dir`: его переписывают только Колесо и Смерть, и переписанный `dir` живёт до конца шага.

| Младший аркан, `sg` = −1 если перевёрнута, иначе +1 | `drift` | `v` | `pull` |
| --- | --- | --- | --- |
| жезлы | `sg`·`m`·0.5 | 1.0 | 0 |
| кубки | 0 | 1.0 + 0.8·`m` прямая, 0.6 + 0.3·`m` перевёрнутая | 0 |
| мечи | `sg`·(±1 от `r() < 0.5`)·`m`·0.35 | 0.8 + 0.6·`m` | 0 |
| пентакли | 0 | 0.8 | `m`·0.3 |

Свеча, всё в единицах `A`:

- `o = last.c + gap·A`
- `c = o + drift·A + (r() − 0.5)·v·A + pull·(ma − o)`
- `h = max(o, c) + r()·v·A·0.6`, `l = min(o, c) − r()·v·A·0.6`; если `h − l < 0.3·A`, обе тени раздвигаются поровну до `h − l = 0.3·A`, чисел генератора это не тратит
- `t = last.t + 1 час`; свеча становится `last` для следующей.

Порядок чисел генератора на одну свечу: мечи берут одно число на знак дрейфа, потом шум close, потом `h`, потом `l`. Шкала откалибрована так, что средний истинный диапазон свечи прогноза — около одного ATR, и ни одна свеча не уже 0.3 ATR; держит `engine/v1/calibration.test.ts`.

## Точность

- Свеча прогноза сравнивается с реальной свечой того же `t`. Попадание — совпал знак: `(fc.c ≥ fc.o) === (real.c ≥ real.o)`.
- `accuracy = hits / compared`, где `compared` — сколько свечей прогноза уже получили реальную пару. Считается по шагам и суммарно.
- `compared = 0` — будущее не наступило, бейджа нет. `accuracy ≥ 0.5` — «Пророчество сбылось на N %», иначе «Рынок отверг пророчество». Итог окончателен, когда `compared = 24 · число шагов`.
- Рядом с бейджем и с любой цифрой толкования стоит дисклеймер — закон 2 в `CLAUDE.md`.

## Толкование

Текст определяется картой и ориентацией, шаблоны перенесены из `tarot-alpha.html`; позиция в шаге (часы 0–8, 8–16, 16–24) — только подпись в интерфейсе. Текст Шута говорит «хаотичное движение», а формула даёт ему ровный дрейф вниз, как всем «остальным старшим» — перенесено как есть. Толкование детерминировано и живёт в движке, потому что меняется вместе с формулами. Толкует ли LLM — задача TA-008.
