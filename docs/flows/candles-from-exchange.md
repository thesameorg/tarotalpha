# Откуда берутся свечи и где они не хранятся

> актуально · 2026-09-10 · браузер и воркер берут закрытые часовые свечи прямо у биржи одним запросом по якорю; первым идёт Bybit, потому что Binance не отвечает с края Cloudflare; хранится только снапшот внутри расклада, кэша и инджеста нет

- Якорь: `anchor_ts = floor(now / 1ч) · 1ч − 1ч` — время открытия последней закрытой свечи. Текущую незакрытую не берём: она меняется внутри часа, а снапшот должен быть одинаков у всех, кто открыл расклад в окне.
- Снапшот: 168 свечей с `endTime = anchor_ts + 1ч − 1`. Для якоря в прошлом запрос тот же и свечи те же. Поэтому воркер при «Поделиться» получает ровно то, что видел автор, не получая свечи от него. Меньше 168 свечей или последняя не на якоре — ошибка `too_old`, расклад не пишется.
- Реальные свечи для проверки пророчества: `startTime = anchor_ts + 1ч`, не больше `24 · число шагов`, только закрытые. Их берёт браузер при открытии ссылки, у того же провайдера, что и снапшот, — иначе точность считалась бы между двумя биржами. Сервер их не хранит: итог считается заново на каждом просмотре, это один запрос с IP зрителя.
- Провайдеры по очереди: Bybit, затем Binance. Порядок такой, потому что Binance и его зеркало `data-api.binance.vision` отвечают 403 на запросы с IP Cloudflare (проверено с края через `wrangler dev --remote`), а Bybit отвечает и браузеру, и воркеру. Код один для браузера и воркера — `exchange/`. Ответ нормализуется в `{t, o, h, l, c}`, `t` — открытие в ms UTC; Bybit отдаёт список от новых к старым — разворачиваем. Провайдер снапшота пишется в расклад полем `source`.
- Лимиты биржи считаются по IP. В браузере это IP пользователя. В воркере — общий IP колокации Cloudflare, поэтому воркер ходит в биржу один раз на расклад и только при «Поделиться». Кэш появится, только если биржа начнёт отвечать воркеру 429: это видно по событию `share_failed`.
- Геоблок: Bybit и Binance закрыты для части регионов (США — 403 и 451). В браузере это IP пользователя — цепочка уходит ко второму провайдеру. Воркер при записи сначала берёт провайдера автора, а если тот недоступен с края — следующего, и пишет фактический в `source`: карты от свечей не зависят, а часовые свечи двух бирж расходятся на сотые доли процента. Недоступны оба — 502 и «повторить».
- Инструмент проверяется маской `^[A-Z0-9]{2,20}$`, существование проверяет биржа: её «неизвестный символ» — наш `unknown_asset`. В браузере это умеет только Bybit: ответ 400 Binance приходит без CORS-заголовков, и браузер видит сетевой отказ, а не код; воркер видит оба. Акции и форекс не поддержаны: провайдеры платные, ключей нет.
- TradingView источником быть не может: виджет — iframe без API, из него не прочитать свечи и на нём не дорисовать прогноз; lightweight-charts — только рендер, данных не носит.
- Лимиты и форматы провайдеров, проверенные живым запросом, — `docs/reference/binance-klines.md` и `docs/reference/bybit-kline.md`.
