# ADR-0010 · Линтер документации не прощает ничего: каждый слой ругается на всё, что видит

> реализовано · 2026-09-12 · хук ругается на любое нарушение в записанном файле, `pre-commit` и `pnpm run check` гоняют полный аудит, как CI; отменяет ADR-0003 в строке «политика документирования на изменённых строках»

Отменяет ADR-0003 в одной строке таблицы; всё остальное из него в силе.

## Контекст

Линтер пришёл с терпимостью к легаси: локальные слои смотрели только файлы из диффа, прощали блок комментариев, в котором дифф написал меньше половины строк, а для долга держали ратчет. Долга у проекта нет: CI гоняет полный аудит на каждом PR, и `main` по нему чист. Терпимость ничего не защищала и только давала CI узнать первым. Шапка, которая выросла с 10 строк до 11 после правки одной строки, проходила хук и `pre-commit` (#33, случилось в #32). Ссылка из нетронутого дока на переименованный файл проходила `pre-commit` и `pnpm run check` (#34).

## Решение

Нарушение чинится сразу, долг не копится. Каждый слой ругается на всё, что видит, без поправки на авторство строк.

| Где | Что гоняется |
| --- | --- |
| PostToolUse-хук на правку агента | политика документирования на записанном файле целиком |
| `pre-commit` на коммит | формат, eslint и `tsc` на застейдженном; полный аудит `scripts/docs_lint.py` — та же команда, что в CI |
| `pnpm run check` | полный аудит плюс предупреждения о доках, отставших от диффа против `origin/main` |

Хук `docs-lint` в `pre-commit` — `pass_filenames: false` и `always_run: true`: без этого коммит, который только удаляет файл, до него не доходит. Что команда в `pre-commit` та же, что в `.github/workflows/check.yml`, держит тест `scripts/test_docs_lint.py`.

## Отвергнуто

- **Доля строк плюс долг по состоянию базы**: блок, который правка вывела за лимит, — долг диффа, чужой долг прощается. Закрывало #33, но оставляло механизм ради долга, которого нет, и не закрывало #34.
- **Диффовый режим узнаёт удалённые пути** и проверяет ссылки на них в нетронутых файлах. Это новый механизм под одно правило; следующее расхождение того же рода пришлось бы чинить снова.
- **CI гоняет `--base` с ратчетом**, как локальные слои. Расхождение пропадает за счёт CI: долг в `main` становится возможным.

## Цена

- Коммит, который ломает ссылку в чужом файле, не пройдёт, даже если её чинит следующий коммит: правка ссылки едет вместе с переименованием.
- Правка файла, где уже есть нарушение, краснеет в хуке, хотя нарушение не её. Пока `main` чист по полному аудиту, так не бывает; появилось — чинится той же правкой.
- Полный аудит стоит около 0,15 с на коммит.
