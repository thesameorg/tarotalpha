# ADR — почему решили именно так

Одно решение — один файл, пронумерованный по порядку. **ADR не редактируют.** Передумали — пишется новый со строкой `Отменяет ADR-NNNN`, старый получает статус `устарело` и ссылку на замену.

Это делает расхождение невозможным: актуальна всегда версия с бо́льшим номером.

ADR пишется в момент принятия решения, а не после. Решение уже в коде и никто не помнит альтернатив — ADR писать поздно, хватит трёх строк в `docs/`.

Следующие решения ждут в `tasks/backlog/`: толкование от модели, OG-картинки.
