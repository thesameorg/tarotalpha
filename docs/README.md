# Документация TarotAlpha

Проза по-русски, термины и код по-английски. Комментарии в коде — по-английски. Как и что здесь пишут: `.claude/skills/documenting/SKILL.md`.

## Как найти нужное

Два входа, третьего нет:

1. **Из кода.** Комментарий даёт путь к документу — ты уже стоишь в нужном месте.
2. **Отсюда.** Строка на документ, и она описывает **вопрос**, а не тему.

Ходить по папкам и смотреть, что есть, не предполагается: если документ не находится по вопросу, он назван неправильно.

## Папки — по вопросу, а не по подсистеме

| Папка | Вопрос |

| [`flows/`](flows/) | что чем триггерится, откуда берёт данные, куда отдаёт |

## Чего здесь нет и не будет

- **Списка того, что сделано.** Это состояние, его место в `tasks/`.
- **Обучающих туториалов.** Читатель — второй разработчик или агент, оба читают код.
- **Разделов «отложено»** внутри документов. Незаконченное — новая задача в `tasks/backlog/`.
- **Секретов.** Ключи в менеджере паролей и в переменных окружения площадки.
