# Документация TarotAlpha

Проза по-русски, код по-английски. Как писать: `.claude/skills/documenting/SKILL.md`.

## Как найти нужное

Два входа: из кода — комментарий даёт путь к документу; отсюда — строка на документ описывает вопрос, а не тему. Документ не находится по вопросу — он назван неправильно.

## Раскладка кода

Один Cloudflare Worker отдаёт SPA как статику и отвечает на `/api/*`. Собирает Vite, деплоит `wrangler`, конфиг — `wrangler.jsonc` в корне.

| Папка | Что там |
| --- | --- |
| `engine/` | движок прогноза: чистый TypeScript без I/O и без импортов платформы; версия — папка (`engine/v1/`), старые версии не удаляются |
| `exchange/` | запросы к биржам за закрытыми свечами: один код для браузера и воркера, без кэша |
| `web/` | клиент: корень Vite, `index.html`, стили, код страницы |
| `worker/` | Worker: обработчик `fetch`, маршруты `/api/*`, доступ к D1 и KV |
| `migrations/` | SQL-миграции D1, применяет `wrangler d1 migrations apply` |
| `.github/` | CI: типы, линт, тесты, сборка и политика документирования на каждом PR; деплой на Cloudflare на пуш в `main` |

## Чего здесь нет и не будет

- **Списка того, что сделано.** Это в `tasks/`.
- **Туториалов.** Читатель читает код.
- **Отложено.** Незаконченное — в `tasks/backlog/`.
- **Секретов.** В менеджере паролей.
