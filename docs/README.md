# Документация TarotAlpha

Проза по-русски, код по-английски. Как писать: `.claude/skills/documenting/SKILL.md`.

## Как найти нужное

Два входа: из кода — комментарий даёт путь к документу; отсюда — строка на документ описывает вопрос, а не тему. Документ не находится по вопросу — он назван неправильно.

## Папки — по вопросу

| Папка | Вопрос |
| --- | --- |
| [`flows/`](flows/) | что чем триггерится, откуда берёт, куда отдаёт |
| [`adr/`](adr/) | почему решили так (заморожено) |
| [`runbooks/`](runbooks/) | как сделать вручную |
| [`reference/`](reference/) | лимиты, форматы, грабли |

## Отдельные документы

| Документ | Вопрос |
| --- | --- |
| [`idea.md`](idea.md) | что строим, как зарабатывает, риски — ТЗ целиком |
| [`glossary.md`](glossary.md) | как называется — одно понятие, одно имя |
| [`maybe.md`](maybe.md) | сырые идеи, ещё не ставшие задачами |

## Чего здесь нет и не будет

- **Списка того, что сделано.** Это в `tasks/`.
- **Туториалов.** Читатель читает код.
- **Отложено.** Незаконченное — в `tasks/backlog/`.
- **Секретов.** В менеджере паролей.

## Проверка

```bash
npm run check       # только изменённые строки
npm run related     # противоречия перед PR
npm run check:all   # весь репозиторий
```
