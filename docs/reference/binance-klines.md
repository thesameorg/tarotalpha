# Binance: klines для снапшота

> справочник · 2026-09-10 · публичный `GET /api/v3/klines` без ключа отдаёт до 1000 часовых свечей за вес 2 при бюджете 6000 в минуту на IP; неизвестный символ — HTTP 400 с `code: -1121`

Используется в `exchange/binance.ts`. Проверено живыми запросами 2026-09-10 и по официальной документации Spot REST API (developers.binance.com).

## Запрос

- `GET https://api.binance.com/api/v3/klines?symbol=BTCUSDT&interval=1h&limit=168&endTime=<anchor_ts + 3600000 − 1>`; для реальных свечей после якоря — `startTime`.
- `limit`: по умолчанию 500, максимум 1000 — `limit=2000` молча отдаёт 1000.
- С `endTime` окно заканчивается на якоре: 168 строк, `openTime` последней равен якорю (проверено для якоря двое суток назад). Без `endTime` последняя строка — незакрытая свеча текущего часа.
- Публичные данные есть и на `https://data-api.binance.vision` — запасной хост, если основной станет отвечать WAF-ом.

## Ответ

Массив массивов по 12 позиций: `[0] openTime` ms, `[1] open`, `[2] high`, `[3] low`, `[4] close`, `[5] volume`, `[6] closeTime` ms, `[7] quoteVolume`, `[8] trades`, `[9] takerBuyBase`, `[10] takerBuyQuote`, `[11] ignore`. Цены и объёмы — строки, время — числа. Порядок — от старых к новым.

## Лимиты и отказы

- Вес запроса 2 при любом `limit`; бюджет IP — 6000 веса в минуту (`exchangeInfo`, `REQUEST_WEIGHT`), израсходованное — в заголовке `x-mbx-used-weight-1m`. Нам это тысячи раскладов в минуту с одной колокации.
- 429 — лимит превышен; 418 — IP забанен за запросы после 429, от 2 минут до 3 дней; 403 — сработал WAF.
- Неизвестный символ: HTTP 400, тело `{"code":-1121,"msg":"Invalid symbol."}`. На этом ответе нет CORS-заголовков: из браузера он выглядит как сетевая ошибка, код виден только с сервера.
- Геоблок: из США и части регионов — HTTP 451 с телом `{"code":0,"msg":"Service unavailable from a restricted location…"}`. В официальной документации не описан, известен по отчётам пользователей; с IP проверки не воспроизводится. Для нас это переход к Bybit.
