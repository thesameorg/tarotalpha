# Rider–Waite–Smith 1909: откуда сканы карт и как они пережаты

> справочник · 2026-09-10 · 78 сканов колоды 1909 года с Wikimedia Commons, общественное достояние; лежат в `web/public/cards/` как `NN.webp` шириной 360 px, NN — id карты из `engine/v1/deck.ts`

Используется в `web/card-image.ts`. Скачано и проверено 2026-09-10.

## Источник и лицензия

- Commons, категория `Category:Rider-Waite-Smith tarot deck (TaionWC)` — в родительской `Category:Rider-Waite tarot deck` самих карт нет, только подкатегории. Старшие арканы — `File:RWS_Tarot_00_Fool.jpg` … `File:RWS_Tarot_21_World.jpg`, младшие — `File:Wands01.jpg` … `File:Wands14.jpg`, так же `Cups`, `Swords`, `Pents`; 01 — туз, 11 — паж, 12 — рыцарь, 13 — королева, 14 — король.
- Общественное достояние: колода издана в 1909 году, художница Памела Колман Смит умерла в 1951-м — истекли и 70 лет после смерти автора, и американский срок для публикаций до 1930 года. У всех 78 файлов в `extmetadata` стоит `LicenseShortName: Public domain`, `Copyrighted: False`, категории `PD-old-80-expired` и `CC-PD-Mark`.
- API и превью отдаются только с описательным `User-Agent`: пустой получает HTTP 403. Ссылка на превью берётся из `imageinfo` (`iiurlwidth=600` Commons округляет до 960 px).

## Имена и пережатие

- `NN` — двузначный id из `engine/v1/deck.ts`: 00–21 старшие арканы по порядку Райдера–Уэйта, дальше 22 + масть × 14 + (ранг − 1): 22 — Туз Жезлов, 36 — Туз Кубков, 50 — Туз Мечей, 64 — Туз Пентаклей, 77 — Король Пентаклей.
- `cwebp -size 25000 -pass 10 -m 6 -sharp_yuv -af -resize 360 0 -metadata none NN.jpg -o NN.webp` (libwebp 1.6.0).
- Фиксированное качество не подошло: растр печати на сканах при `-q 78` даёт 33–75 КБ на карту и 4,5 МБ на колоду; целевой размер 25 КБ держит колоду в 1,9 МБ ценой качества ~40–55, штриховка при 360 px не страдает.
