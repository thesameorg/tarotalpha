# Bybit: kline для снапшота

> справочник · 2026-09-10 · публичный `GET /v5/market/kline` без ключа отдаёт до 1000 свечей списком от новых к старым; неизвестный символ — HTTP 200 с `retCode: 10001`, региональный отказ — HTTP 403

Используется в `exchange/bybit.ts` как запасной провайдер. Проверено живыми запросами 2026-09-10 и по официальной документации API v5 (bybit-exchange.github.io).

## Запрос

- `GET https://api.bybit.com/v5/market/kline?category=spot&symbol=BTCUSDT&interval=60&limit=168&end=<anchor_ts + 3600000 − 1>`; для реальных свечей после якоря — `start`. `interval` — минуты (`60`), не `1h`; `category` обязателен, иначе подразумевается `linear` (фьючерсы).
- `limit`: по умолчанию 200, максимум 1000 — `limit=1001` молча отдаёт 1000.
- `end` включает свечу, открытую на якоре: 168 строк, `startTime` первой (самой новой) равен якорю (проверено для якоря двое суток назад).

## Ответ

`{"retCode":0,"retMsg":"OK","result":{"category","symbol","list":[…]}}`; элемент `list` — 7 позиций: `[0] startTime` ms, `[1] open`, `[2] high`, `[3] low`, `[4] close`, `[5] volume`, `[6] turnover`. Всё строками, включая время. **Список отсортирован по `startTime` в обратном порядке — от новых к старым**, `exchange/bybit.ts` разворачивает.

## Лимиты и отказы

- По IP: 600 запросов за 5 секунд; превышение — HTTP 403 «access too frequent» и бан IP не меньше чем на 10 минут. Заголовки `X-Bapi-Limit*` описаны для эндпоинтов с ключом, публичный kline их не присылает (проверено).
- Ошибки приходят с HTTP 200: неизвестный символ — `{"retCode":10001,"retMsg":"Not supported symbols"}` (10001 — общий «ошибка параметра»); `10006` — лимит эндпоинта; `10009` — «Service Restricted», регион не обслуживается.
- Геоблок: с IP из США документация обещает HTTP 403 ещё до `retCode`; с IP проверки не воспроизводится.
