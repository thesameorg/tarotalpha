| Документ | Что сверяют |
| --- | --- |
| [`binance-klines.md`](binance-klines.md) | формат строки klines, максимум `limit`, вес и бюджет на IP, что отдаёт Binance на неизвестный символ и из закрытого региона |
| [`bybit-kline.md`](bybit-kline.md) | формат строки kline, порядок списка (от новых к старым), лимит на IP, коды `retCode` на неизвестный символ и регион |
