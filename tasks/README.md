# Задачи

Трекер — эта папка. Задача — файл, статус — папка, история — `git log`. Внешнего трекера нет и не заводим: на проекте один разработчик и агенты, а лишний сервис означает, что состояние живёт в двух местах и расходится.

## Статус — это папка

| Папка | Значит |
| --- | --- |
| `backlog/` | заведена, гейт-4 не пройден, работа не начата |
| `active/` | владелец сказал «да», есть ветка, работа идёт |
| `done/` | смержено в `main` |
| `dropped/` | не будет сделана; первая строка файла говорит почему |

Переход статуса — `git mv`. Имя файла при этом не меняется, поэтому история задачи не рвётся.

## Имя

`TA-NNN-<слаг>.md`, номер сквозной по всем четырём папкам, слаг — то же имя, что у ветки: `TA-003-candle-parser.md` → `feat/candle-parser`. Номер выдаёт `/task-new`, он же считает следующий свободный.

Имя обещает, что внутри. `TA-007-fix-stuff.md` не задача, а напоминание, что кто-то поленился.

## Что внутри

```markdown
# TA-001 · Схема деплоя

> ветка: не заведена · PR: нет

**Зачем.** Что сломано или чего не хватает. Факт, а не пересказ желания.
**Что меняется.** Одна строка в терминах `docs/glossary.md`: каким процесс был и каким станет. Она же — первая строка описания PR.
**DoD.** Одна проверяемая строка, по которой можно кликать или прогнать тест.
**Как чиню.** Три-четыре строки. Альтернатива называется, только если она правда спорная.
**Разведка.** Переиспользую · завожу новое · сломается · не трогаю · пропустил.
**Цена.** Токены, внешние API, время прогона.
```

В `backlog/` заполнены только «Зачем», «Что меняется» и черновой DoD. Остальное появляется на шаге 3 — это и есть оценка, которую владелец читает на гейте-4.

Два экрана. Не влезло — работу пересказали вместо того, чтобы разведать.

## Чего в задаче нет

- **Знания.** Закрытая задача — след, а не архив. «Почему решили» уезжает в `docs/adr/`, устройство — в `docs/flows/`, факт — в `docs/reference/`. Файл в `done/` может ссылаться на них, но сам объяснением не является.
- **Прогресса.** «Сделано 60 %», «остался хвост» — это состояние, оно живёт в ветке и в PR.
- **Списка подзадач на потом.** Не влезло в эту задачу — новая задача, со своим номером.

## Порядок

Приоритет здесь не считают: разработчик один, очереди нет. Порядок задаёт блокировка — что чему мешает, написано в самих файлах строкой «ждёт TA-NNN». Пока схема деплоя не выбрана, раскладка файлов и оснастка не начинаются: и то и другое зависит от неё целиком.
