# Задачи

Трекер — эта папка. Задача — файл, статус — папка, история — `git log`.

## Статус — это папка

| Папка | Значит |
| --- | --- |
| `backlog/` | гейт-4 не пройден, работа не начата |
| `active/` | владелец согласен, есть ветка |
| `done/` | в `main` |
| `dropped/` | не будет сделана; первая строка файла говорит почему |

Переход статуса — `git mv`: имя файла не меняется, история задачи не рвётся.

## Имя

`TA-NNN-<слаг>.md`, номер сквозной по всем четырём папкам, слаг — имя ветки. Выдаёт `/task-new`. Имя обещает, что внутри: `TA-007-fix-stuff.md` — не задача.

## Что внутри

```markdown
# TA-001 · Схема деплоя

> ветка: не заведена · PR: нет

**Зачем.** Что сломано или чего не хватает. Факт, а не пересказ желания.
**Что меняется.** Одна строка в терминах `docs/glossary.md`: каким процесс был и каким станет. Она же — первая строка описания PR.
**DoD.** Одна проверяемая строка, по которой можно кликать или прогнать тест.
**Как чиню.** Три-четыре строки. Альтернатива называется, только если она правда спорная.
**Разведка.** Переиспользую · завожу новое · сломается · не трогаю · пропустил.
**Цена.** Токены, внешние API, время прогона.
```

В `backlog/` заполнены «Зачем», «Что меняется» и черновой DoD; остальное появляется на оценке, шаг 3. Два экрана — не влезло, значит не разведано.

## Чего в задаче нет

- **Знания.** «Почему» в `docs/adr/`, устройство в `docs/flows/`, факты в `docs/reference/`.
- **Прогресса.** Состояние в ветке и PR.
- **Подзадачи.** Не влезло — новая задача в `tasks/backlog/`.
