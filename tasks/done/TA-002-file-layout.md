# TA-002 · Раскладка файлов

> ветка: feat/prototype · PR: https://github.com/thesameorg/tarotalpha/pull/1

**Зачем.** Пустой репозиторий — единственный момент, когда раскладку можно выбрать, а не разгребать. Фронт, воркеры, движок прогноза и общие типы должны лежать так, как того требует выбранная площадка, а не так, как привык предыдущий проект.

**Что меняется.** Появляется ответ на «куда класть новый файл», и он один на весь проект.

**DoD.** Раскладка описана в `docs/README.md` строкой на папку; `npm run check:all` зелёный на пустом каркасе.

**Как чиню.** Один `package.json` без воркспейсов: `engine/` (чистые формулы, `engine/v1/` — версия), `exchange/` (свечи с биржи, общий код браузера и воркера), `web/` (Vite-клиент), `worker/` (маршруты и данные), `migrations/` (SQL для D1), `.github/` (CI). Почему так — ADR-0001.

**Разведка.** Переиспользую: линтер `scripts/docs_lint.py` и его `GENERIC_NAMES` как ограничение на имена. Завожу новое: шесть папок. Сломается: ничего. Не трогаю: `tarot-alpha.html` остаётся в корне как образец визуала до конца прототипа. Пропустил: «История» — репозиторий пустой.

**Цена.** Ноль внешних вызовов.

**Ждёт.** TA-001.
