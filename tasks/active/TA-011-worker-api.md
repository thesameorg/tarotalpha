# TA-011 · API воркера: запись расклада, ссылка, мета-теги, события

> ветка: feat/prototype · PR: нет

**Зачем.** Без сервера нет ни ссылки, ни снапшота, ни счётчика — а ссылка с проверкой пророчества и есть то, что шарят. HTML отдавал расклад кодом в textarea.

**Что меняется.** Расклад становится сущностью с короткой ссылкой: «Поделиться» пишет строку в D1 со снапшотом, снятым воркером, ссылка отдаёт снапшот и карты, а превью в телеге получает мета-теги расклада. Свечи при этом никто не хранит и не кэширует.

**DoD.** В `vite dev` цепочка проходит curl'ом: `POST /api/readings` для `BTCUSDT` с якорем на двое суток назад → `GET /api/readings/:id` отдаёт 168 свечей с последней на якоре и три шага карт, равных `computeSteps` движка; `GET /r/:id` отдаёт HTML с `og:title`, содержащим тикер; `steps: 4` — 402; сто запросов подряд с одного IP — 429; `GET /api/stats/today` растёт после `POST /api/events` с `step_opened`.

**Как чиню.** Маршруты по `docs/flows/reading-lifecycle.md`, свечи через общий `exchange/` по `docs/flows/candles-from-exchange.md`. D1 — одна миграция на `readings` и `events`. Лимит по IP — binding Rate Limiting, если работает локально, иначе счётчик в памяти изолята; KV не заводим. Факты о провайдерах, проверенные живым запросом, — в `docs/reference/`.

**Разведка.** Переиспользую: движок TA-010, `exchange/`. Завожу новое: `worker/reading-page.ts` — вписывание мета-тегов через HTMLRewriter, потому что краулеры JS не выполняют. Сломается: ничего. Не трогаю: OG-картинки — TA-012; cron — нечего запускать. Пропустил: «История».

**Цена.** Запросы к Binance и Bybit при тестах — единицы, публичные, без ключей. В аккаунте Cloudflare ресурсы создаёт TA-013, здесь всё локально.
