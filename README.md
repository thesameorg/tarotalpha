# TarotAlpha

Сайт с внешностью финтех-терминала, внутри — таро-расклад, который дорисовывает свечной график на сутки вперёд. Шутка держится на контрасте серьёзной подачи и абсурдного содержания. ТЗ целиком: `docs/idea.md`.

## Расклад детерминирован, и это задумано

Сид тасовки считается от инструмента, якоря, номера шага и версии движка. Якорь — время последней закрытой свечи, поэтому **окно фиксации равно таймфрейму**: на 1H расклад по одному инструменту один и тот же для всех, кто открыл его в течение часа, и меняется на границе следующей свечи.

Что из этого следует:

- «Расклад дня» — не отдельная механика, а следствие: одно окно, один расклад на всех.
- Дуэль двух пользователей на один инструмент внутри одного окна идёт только гадалками: карты у обоих одни и те же, а свечи и точность зависят от того, кого выбрали.
- «Переоткрыть расклад» и «второе мнение» внутри окна ничего не меняют: карты те же.

**Энтропии нет.** Переключатель `SEED_ENTROPY` в `wrangler.jsonc` стоит `off`. С `on` в сид вошёл бы нонс самого расклада и карты стали бы у каждого свои, но нонс никто не выдаёт, и воркер на `on` отвечает 501.

Ссылка хранит выпавшие карты, выбранную гадалку и снапшот свечей. Формулы движка правятся на месте, поэтому свечи прогноза по старой ссылке могут измениться после правки — карты и снапшот нет. Как считается и где ссылка может разойтись с увиденным — `docs/engine.md`.

## Команды

```bash
pnpm run dev              # клиент и воркер локально, docs/architecture.md
pnpm run test             # движок, биржевые адаптеры, воркер
pnpm run wt feat/foo   # дерево под задачу
pnpm run check            # политика документирования по всему репозиторию плюс доки, отставшие от PR
pnpm run check:all        # то же без сверки с PR — ровно то, что гоняет CI
```
