# TarotAlpha

Сайт с внешностью финтех-терминала, внутри — таро-расклад, который дорисовывает свечной график на сутки вперёд. Шутка держится на контрасте серьёзной подачи и абсурдного содержания. ТЗ целиком: `docs/idea.md`.

## У каждого расклада свой рандом

Карты тянет детерминированный генератор, но в его сид входит нонс — 64 случайных бита, свои у каждого расклада. Браузер заводит нонс на расклад и шлёт при записи, воркер по нему же вытягивает карты и хранит его в строке.

Что из этого следует:

- Два человека, открывшие BTCUSDT в один и тот же час, видят разные карты. Общего расклада на всех нет.
- Перезагрузка страницы, другой инструмент и просто следующее открытие — это новый расклад с новыми картами, отдельной строкой в базе и своей ссылкой.
- Дуэль двух пользователей на один инструмент — это два разных расклада: и карты, и гадалки у них свои.
- Ссылка воспроизводится: карты, гадалка, снапшот и нонс лежат в самом раскладе, а не выводятся из часа.

Формулы движка правятся на месте, поэтому свечи прогноза по старой ссылке могут измениться после правки — карты и снапшот нет. Как считается и где ссылка может разойтись с увиденным — `docs/engine.md`.

## Команды

```bash
pnpm run dev              # клиент и воркер локально, docs/architecture.md
pnpm run test             # движок, биржевые адаптеры, воркер
pnpm run wt feat/foo   # дерево под задачу
pnpm run check            # политика документирования по всему репозиторию плюс доки, отставшие от PR
pnpm run check:all        # то же без сверки с PR — ровно то, что гоняет CI
```
