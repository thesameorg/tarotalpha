# Уборка

Уборка ничего не считает заново. Всё, что ей нужно, уже посчитано — `git`, `gh`, `scripts/docs_lint.py`, папки `tasks/`. Её работа: задать пять вопросов подряд и не дать ни одному остаться без ответа.

**Две границы.** Молча чинит только безоговорочно обратимое: смерженную ветку, дерево без изменений. Всё остальное докладывает владельцу. Один заход: красное на втором — стоп и строка владельцу.

## 1. Ветки и деревья

```bash
git fetch --prune
git branch --merged origin/main | grep -vE '^[*+]|main'   # снести; + значит занята деревом
git worktree list                                          # чистые — снять
git for-each-ref --sort=committerdate --format='%(refname:short) %(committerdate:relative)' refs/heads
```

Ветка старше двух недель без PR — вопрос владельцу: доделываем или сносим.

## 2. Задачи

- Что лежит в `tasks/active/` без ветки или с закрытым PR? Либо доехало и едет в `done/`, либо не начиналось и едет обратно в `backlog/`.
- Что лежит в `backlog/` дольше месяца и не сдвинулось? Кандидат в `dropped/` — со строкой почему.
- У чего в `active/` нет DoD? Это не задача, это пожелание.

## 3. Долг документации

```bash
npm run check:all
```

Число находок сравнивается с прошлой уборкой. Растёт — значит ратчет на пуше кто-то обходил.

## 4. Доки, которые начали врать

Документы со статусом `актуально` и датой старше трёх месяцев. Открыть, проверить по коду, поменять статус или дату. Документ, который никто не открывал полгода и который не описывает работающий код, — кандидат на `устарело`.

## 5. Итог

Пять строк владельцу: что снесено, что зависло, куда растёт долг, что требует решения. Список без вывода итогом не является.
