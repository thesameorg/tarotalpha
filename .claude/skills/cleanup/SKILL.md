# Уборка

Пять вопросов подряд, ни одному не избежать. Молча чинит только смерженные ветки и деревья без изменений. Всё остальное — владельцу. Красное на втором — стоп.

## 1. Ветки и деревья

```bash
git fetch --prune
git branch --merged origin/main | grep -vE '^[*+]|main'   # снести; + значит занята деревом
git worktree list                                          # чистые — снять
git for-each-ref --sort=committerdate --format='%(refname:short) %(committerdate:relative)' refs/heads
```

Старше двух недель без PR — вопрос владельцу.

## 2. Issues

```bash
gh issue list --state open
gh pr list --state open
```

- Открытая issue, чей PR смержен, но не закрыл её строкой `Closes #N`: закрыть со ссылкой на PR.
- Открытая дольше месяца без ветки: кандидат на закрытие, вопрос владельцу.
- Без DoD: не задача, на гейт-4 не носить.

## 3. Долг документации

```bash
pnpm run check:all
```

Ноль — норма. Не ноль — обход хуков.

## 4. Доки, которые начали врать

`актуально` и дата старше трёх месяцев: проверить, обновить. Полгода закрыта — `устарело`.

## 5. Итог

Пять строк владельцу: снесено, зависло, долг, решить. Не список.
