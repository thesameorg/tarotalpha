Из строки: **$ARGUMENTS**

Issue заводят руками или по прямому указанию — эта команда и есть указание. Небольшое и проговорённое в беседе issue не требует (`CLAUDE.md`, раздел «Задача»).

1. Дубль: `gh issue list --search "<слова>"`. Есть похожая — уточнить её через `gh issue edit`, вторую не заводить.
2. Заголовок — что меняется, в терминах `docs/glossary.md`; он же станет первой строкой PR.
3. Тело — три блока: **Зачем** (факт, а не пересказ желания), **Что меняется** (одна строка: каким процесс был и каким станет), **DoD** (одна проверяемая строка). Блокировка — строка `blocked by #N`.
4. `gh issue create --title "..." --body-file -`. Показываешь ссылку. Работу не начинаешь.
