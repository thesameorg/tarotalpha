description: Завести задачу в tasks/backlog со следующим свободным номером
argument-hint: "кэш свечей жжёт лимит биржи"
---

Из строки: **$ARGUMENTS**

1. Номер: `ls tasks/*/ | grep -o 'TA-[0-9]*'`. Не переиспользуют.
2. Слаг — два-три слова для ветки. Обещает содержимое.
3. `tasks/backlog/TA-NNN-<слаг>.md` по `tasks/README.md`. Заполнить: «Зачем», «Что меняется», DoD.
4. Блокировка: строка «Ждёт TA-NNN», и «Блокирует TA-NNN» в той задаче. Дубль в `backlog/` — уточнить старую. Показываешь файл. Работу не начинаешь.
