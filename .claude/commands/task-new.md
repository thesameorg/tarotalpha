---
description: Завести задачу в tasks/backlog со следующим свободным номером
argument-hint: "кэш свечей жжёт лимит биржи"
---

Заводишь задачу из строки: **$ARGUMENTS**

1. Следующий свободный номер — по всем четырём папкам сразу: `ls tasks/*/ | grep -o 'TA-[0-9]*'`. Номера не переиспользуют, даже освободившиеся.
2. Слаг — по-английски, два-три слова, то же имя пойдёт ветке. Имя обещает, что внутри: `fix-stuff` не имя.
3. Файл `tasks/backlog/TA-NNN-<слаг>.md` по шаблону из `tasks/README.md`. В бэклоге заполняешь только «Зачем», «Что меняется» и черновой DoD — остальное появится на оценке.
4. Есть блокировка — пишешь строкой «Ждёт TA-NNN» и, если блокируешь чужую, «Блокирует TA-NNN» в той.

Дубль проверяешь до того, как завёл: то же самое другими словами в `backlog/` — не новая задача, а повод уточнить старую.

Показываешь получившийся файл целиком. Работу не начинаешь: заведение задачи и гейт-4 — разные события.
