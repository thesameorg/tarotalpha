---
description: Полный локальный прогон — то, чем краснеет CI, плюс то, что он не смотрит
---

Все по порядку, не стоп на первом красном:

```bash
pnpm run check          # политика документирования по всему репозиторию плюс доки, отставшие от PR
pnpm run related        # доки, которые могли начать врать
pnpm run test:lint      # тесты самого линтера
pre-commit run --all-files
pnpm run test           # в pre-commit их нет, а CI краснеет
pnpm run build
```

Разбор вывода:

- **Формат** — автоматически, коммит отдельно.
- **Политика** — `.claude/skills/documenting/SKILL.md`. Механическое — `lint-fixer`, спорное сам.
- **`related`** — по каждому названному документу читаешь вердикт во второй строке; целиком открываешь только тот, что про сделанное, и отвечаешь, противоречит ли он. «Не про это» валиден, молчание — нет.

Отчёт — три строки: что красное, что починено, что осталось и почему.
