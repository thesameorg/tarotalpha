---
description: Полный локальный прогон — то, чем краснеет CI, плюс то, что он не смотрит
---

Прогоняешь по порядку и не останавливаешься на первом красном — собираешь всё:

```bash
npm run check          # политика документирования на изменённом
npm run related        # доки, которые могли начать врать
npm run test:lint      # тесты самого линтера
pre-commit run --all-files
```

Дальше разбираешь вывод:

- **Формат** — правится автоматически, коммитится отдельно, в отчёт не идёт.
- **Политика документирования** — чинится по `.claude/skills/documenting/SKILL.md`. Механическое отдаёшь субагенту `lint-fixer`, спорное решаешь сам.
- **`related`** — открываешь каждый названный документ и отвечаешь, противоречит ли он сделанному. Ответ «не про это» валиден, молчание — нет.

Отчёт — три строки: что красное, что починено, что осталось и почему.
