Задачу **$1** ведёшь по `CLAUDE.md`. Расхождение — `CLAUDE.md` главнее.

## 0. Своё место

`pnpm run wt <ветка>` под задачу, слагом из имени файла: `TA-003-candle-parser.md` → `feat/candle-parser`.

## 1. Триаж — дёшево, до разведки

Четыре проверки: существует то, о чём она; не сделано попутно; нет дубля в `backlog/`; есть DoD. Мертва — `tasks/dropped/` с причиной. Устарела — переписать.

## 2. Разведка

Субагентом `recon` — `.claude/agents/recon.md`.

## 3. Оценка

Заполнить: «Как чиню», «Разведка», «Цена», «Что меняется», «DoD». В `tasks/active/`, шапка `> ветка: feat/... · PR: нет`.

**Это и есть гейт-4:** показываешь сам файл, а не пересказ. Два экрана. Дальше стоп: «да», «нет» или «не так». «Не так» — переигранный план, а не отменённая задача: возвращаешься к шагу 3.

## 5–7. Между гейтами

Вопросов не задаёшь. Код, тесты, `pnpm run check`, `pnpm run related`, критик, ветка, PR, CI зелёный, DoD построчно. Две попытки на красное, потом стоп с текстом ошибки. Находки: сказать, мелкое чинить, дыру везде, задачу на неподъёмное. Дерево после PR.

## Гейт «вижу»

- **PR.** Ссылка, CI зелёный.
- **Что меняется.** Строка из файла и первая строка PR.
- **DoD.** Строка из файла, чем подтверждена.
- **Что ещё в PR.** Находки по дороге, по строке.
- **Что ушло из PR.** Отдельные PR и задачи, по строке.
- **Смотреть здесь.** Куда ткнуть за минуту.

Мержит владелец. Дифф не читают. После — в `tasks/done/`.
