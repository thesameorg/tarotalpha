Ведёшь задачу **$1** по разделу «Порядок работы» из `CLAUDE.md`. Здесь только то, чего в нём нет. Расхождение — `CLAUDE.md` главнее этого файла.

## 0. Своё место

`npm run wt -- <ветка>` под задачу. Ветка называется слагом из имени файла задачи: `TA-003-candle-parser.md` → `feat/candle-parser`.

## 1. Триаж — дёшево, до разведки

Открой файл задачи. Четыре дешёвые проверки:

- существует ли ещё то, о чём она написана;
- не сделано ли попутно — `git log` по трогаемым файлам;
- нет ли в `tasks/backlog/` того же самого другими словами;
- есть ли DoD, и проверяемый ли он.

Задача мертва — переносишь файл в `tasks/dropped/`, первой строкой пишешь почему, и разведки не было. Формулировка устарела, а проблема жива — приносишь переписанную.

## 2. Разведка

Субагентом `recon`. Оси и правила их пропуска описаны в скилле, здесь их не пересказывают.

## 3. Оценка

Заполняешь в файле задачи «Как чиню», «Разведка», «Цена» и уточняешь «Что меняется» и «DoD». Файл переносишь в `tasks/active/`, шапку правишь на `> ветка: feat/... · PR: нет`.

**Это и есть гейт-4.** Показываешь владельцу сам файл, а не пересказ. Два экрана. Не влезло — работа не разведана, переписывай.

Дальше стоп: ждёшь «да», «нет» или «не так». «Не так» означает переигранный план, а не отменённую задачу: возвращаешься к шагу 3 с новой вводной.

## 5–7. Между гейтами

Вопросов не задаёшь. Код, тесты, `npm run check`, `npm run related`, критик субагентом, ветка, PR, зелёный CI, разбор находок, сверка DoD построчно.

Две попытки на любое красное, потом стоп с текстом ошибки. Находки — по разделу «Найденное по ходу дела»: сказать сразу, мелкое чинить здесь же отдельным коммитом, дыру чинить независимо от размера, задачу заводить только на неподъёмное.

Дерево сносишь сам, сразу после того как открыл PR.

## Гейт «вижу»

- **PR.** Ссылка, CI зелёный.
- **Что меняется.** Строка из файла задачи, уточнённая по факту. Она же — первая строка описания PR.
- **DoD.** Строка из файла задачи и чем именно она подтверждена.
- **Что ещё в PR.** Находки, починенные по дороге, по строке на каждую.
- **Что ушло из PR.** Отдельные PR и заведённые задачи, по строке.
- **Смотреть здесь.** Куда ткнуть, чтобы увидеть работающее за минуту.

Владелец смотрит и мержит. Дифф на этом шаге не читают. После мерджа файл задачи едет в `tasks/done/`.
